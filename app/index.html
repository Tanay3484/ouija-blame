OuijaBlame

Every codebase has a line nobody dares delete. The person who knew why it is there has left. Ask the line, and the ghost of whoever wrote it answers, only in words they actually wrote, each one linked to the commit, pull request or review where they wrote it. If they never wrote the reason down, the ghost says so.

    Haunted lines

    Each of these lines was deleted by someone who thought it was pointless. It broke, and it was put back. Each séance only heard what was written before the deletion, so you can check what the ghost said against why the line really had to come back.

    Hold your own séance

    Your own GitHub token (optional)

    GitHub lets each browser make 60 calls an hour, about two séances. A token raises that. It stays in this tab, is sent only to api.github.com, and never reaches our server. A fine-grained token with no permissions is enough for public repos.

    Live séances take repos up to 150 MB. The medium runs on a small CPU and can take a minute.

    How the séance works

    1. Walk the line back. git blame shows the last commit that touched a line, which is often a reformat. git log -L follows the line back through every change to the commit that first wrote it.
    2. Gather what was written. Commit messages, the pull requests behind them, review comments, linked issues, and agent-session prompts when a commit has an Entire checkpoint.
    3. The medium points. Gemma, an open-weight model, reads the closest passages and picks up to three that say why the line exists. It can only pick passage numbers. It cannot write a word of the quote.
    4. Code checks every word. Each quote must appear word for word in its source, or it is thrown out. If nothing is left, the ghost says “I never wrote down why.”

    Ground rules

    • Only public words, always with a link to where they were written.
    • The medium's own words are shown apart and labelled as the model's.
    • The people here left projects. They moved on; nobody here died. The ghost is a generic sprite, never a photo.
